# 423002 四孔模挤压 — 示例算例

本目录是"模型 + 材料 → 仿真 → 指标 → 优化 → 复算"整条链路在真实课程设计上的落地记录。

## 1. 算例概况

| 项 | 内容 |
|---|---|
| 产品 | 423002 四孔空心型材（1.25 mm 薄壁） |
| 坯料 | AA6060 等效材料（库内用 ALUMINUM-6061/6082 代用，报告中已写明） |
| 坯料/模具/挤压筒/压杆温度 | 460 / 450 / 430 / 480 °C |
| 杆速 | 4 mm/s（对比组 3 / 4.5 / 5） |
| 摩擦（模–坯 / 筒–坯 / 杆–坯） | 0.4 / 0.8 / 0.3（剪切因子 m） |
| 网格 | 四面体 613 704 单元 / 137 614 节点 |
| 算法 | 稳态 ALE（STYPE=4），另有瞬态 Lagrangian 动画版 |

## 2. 指标定义（与 `scripts/key_metrics.py` 一致）

- 出口截面：z = −10 mm，带宽 ±0.5 mm（该模型出口面 z = −18，z = +10 仍在挤压筒内）。
- 出口速度均值：截面节点速度模长的平均。
- 孔间差：四个象限（按 x/y 符号）平均速度的 (max−min)/mean × 100%。
- 温度/应变/应力：全域与截面的 min / max / mean / p95。

## 3. 基线结果（dof_c1，可复现）

`metrics_dof_c1.json` 由 `key_metrics.py` 从 `dof_c1_out.KEY`（283.6 MB）计算得到：

| 指标 | 数值 |
|---|---|
| 单元 / 节点 | 613 704 / 137 614 |
| 出口速度均值 | 99.74 mm/s（截面） |
| 孔间差 | 10.00% |
| 出口截面温度 | 494.1 ～ 526.6 °C（均值 518.4） |
| 等效应变 | 0.008 ～ 4.61（均值 4.25） |
| 等效应力（von Mises） | 0.88 ～ 80.3 MPa（均值 26.8） |

理论出口速度（按面积比）：112.945 mm/s。本截面取在模口内，速度尚未完全发展，故均值低于理论值；取出口面外侧截面会接近理论值——**报告里必须写清截面位置**。

## 4. 优化循环（项目记录）

| 轮次 | 改了什么 | 结果 | 结论 |
|---|---|---|---|
| 基线 | 等长工作带 | 孔间差 10.36%，速度 CV 30.89%，挤压力 5.176 MN | — |
| 第 1 轮 | 工作带按 3/4/5 分区（四个孔分区加长） | 孔间差 7.81%，CV 24.82%，挤压力 5.769 MN | 流速均匀性改善，代价是挤压力上升 11% |
| 第 2 轮 | L9 正交：杆速 / 坯料温度 / 换热系数 | 三因素对孔间差极差 0.11～0.17 个百分点；挤压力由杆速主控（极差 0.404 MN）；最高温度由换热（32.0 °C）与杆速（24.0 °C）主控 | 工作带分区的收益远大于工艺参数微调 |

> 说明：第 1、2 轮的算例文件（每个 160 MB 的 `.DB`）未随仓库发布；上表是项目记录值。基线 `dof_c1` 的指标可由本目录 JSON 复现。

## 5. 从基线到优化，脚本怎么走

```powershell
# 基线
python scripts/key_metrics.py dof_c1_out.KEY --z-exit -10 --tol 0.5 -o metrics_dof_c1.json
# 优化方案（同样导出 KEY 后）
python scripts/key_metrics.py opt_out.KEY --z-exit -10 --tol 0.5 -o metrics_opt.json
# 对比报告
python scripts/make_report.py -i metrics_dof_c1.json metrics_opt.json -o report.html
```

## 6. 瞬态动画版（tr 算例）

- `tr.DB`：15 帧（Step −1 ～ 13），行程 2.42 mm，时间 0.606 s，含传热。
- 温度范围 455 ～ 472 °C：上端接触 480 °C 压杆升温，筒壁接触 430 °C 降温，模口变形热出现高温环，料头端面降到 455 °C。
- 局限：模口最小单元 0.79 mm、壁厚 1.25 mm，只够 1.6 层单元；跑 2.4 mm 行程即触发 `bad element shape` 与重划循环。改法见 `references/02_meshing.md`。

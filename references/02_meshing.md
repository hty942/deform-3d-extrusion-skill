# 网格标准

判定分三层：画之前定尺寸、画完看质量、跑起来看行为。

## 1. 尺寸准则（画之前）

核心：**单元尺寸要跟得上局部变形梯度**。

| 准则 | 要求 | 说明 |
|---|---|---|
| 单元边长 | ≤ 局部特征尺寸的 1/3～1/5 | 特征尺寸 = 壁厚、工作带高度、圆角半径 |
| 厚度方向层数 | ≥ 3～5 层 | 薄壁挤压最关键的一条 |
| 工作带长度方向 | ≥ 8～10 层 | 保证入口/出口梯度可分辨 |
| 每步位移 | ≤ 最小边长的 1/3～1/5（保守 1/10） | 步长与网格配套，加密后步长必须同步减小 |
| 刚体件 | 可以很粗，但必须划 | 只提供接触面 |

## 2. 质量准则（画完看）

| 指标 | 合格线 |
|---|---|
| 单元体积 | 全部 > 0，无负体积/零体积 |
| 四面体 condition number | 0.6～1.0 占 85～90%，< 0.2 接近 0 |
| 长宽比 | 最长边 / 最短边 < 10 |
| 水密性（塑性体） | 每条边恰被 2 个三角面共用 |

**注意**：质量分布是全局统计，破坏往往发生在局部。全局分布很漂亮也可能在模口炸掉——要盯最小值和报错位置。

## 3. 运行准则（跑起来看）

- 不出现 `Program stopped because of bad element shape!`
- 重划（Remeshing）次数远小于步数，每次重划后还能继续推进
- 相对干涉（relative interference）不触顶（默认限值 0.7）

## 4. 验收：网格无关性

粗/中/细三套（单元数约 1 : 2 : 4），比较**挤压力、出口速度、最高温度**，差值 < 2～5% 才算无关。
做不了就如实写"网格规模受计算资源限制"，并给出已用网格数。

## 5. DEFORM v11 里怎么设（程序内核对过的名称）

| 功能 | 名称 |
|---|---|
| 单元尺寸 | `Mesh → Generate Mesh`：`Min Element Size` / `Max Element Size` / `Relative Element Size` |
| 局部加密 | `Mesh Density Windows`：窗口 + `Weighting Factor`（2～4） |
| 六面体 | `Generate Brick Mesh`（brick，未本机实测；复杂型腔不建议） |
| 重划判据 | `Global / Local Remeshing`、`Interference depth`、`Remesh stroke increment`、`time increment` |

## 6. 单元类型对精度的影响

| | 四面体（4 节点） | 六面体 brick（8 节点） |
|---|---|---|
| 公式 | 4-node tet with **nodal pressure**（混合 u/p） | Brick(STD) / assumed strain |
| 应变 | 单元内近似常数，偏刚 | 三线性 |
| 同等精度所需数量 | 多 2～4 倍（经验值，非本机对比实测） | 基准 |
| 接触面 | 三角面，曲面拟合差 | 四边面，更贴合 |
| 复杂型腔 | 适应性强 | 生成困难 |
| 大变形重划 | 成熟 | 退化快 |

结论：复杂型腔（如四孔模）走"四面体 + 局部加密"；规则件可考虑 brick。

## 7. 内存与单元预算（本机实测经验）

| 单元数 | 16 GB 机器 |
|---|---|
| ≤ 20 万 | 轻松 |
| 60 万 | 可跑（稳态 613 704 单元跑过） |
| 130 万 | 跑不动（可用内存不足） |

## 8. 一个反面案例（423002 四孔模，实测）

- 壁厚 1.25 mm，模口最小单元边 0.79 mm → 厚度方向 1.6 层 → 瞬态跑 2.4 mm 行程就在模口 `bad element shape`，反复重划原地打转。
- 正确目标：模口 0.25～0.3 mm（4～5 层），其余 0.8～1.2 mm；总单元 60 万以内；步长降到 0.1 mm/步。
- 加密顺序：先只加**一个模口密度窗口**（覆盖工作带 ±10 mm，weight 3），跑 20 步验证不再炸，再谈长行程。

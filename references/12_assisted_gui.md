# 让 AI 代操作界面（assisted GUI）

当必须走 L2（建模/划网格）而又希望 AI 代点时，可以用"截图 → OCR/测量 → 点击 → 复验"的闭环。
本项目在 DEFORM-3D v11 上实跑过这套方法（完成开传热、生成库、启动求解、Post 播放等操作）。

## 1. 基本闭环

1. 截图（PowerShell + System.Drawing 截全屏）。
2. 识别：Windows.Media.Ocr 取文字坐标；图标等无文字元素用放大裁剪目测。
3. 点击：SetCursorPos + mouse_event（不是 SendKeys——很多模态框不吃键盘）。
4. 复验：再截一张，确认状态真的变了；没变就重新测量，不要连点。

## 2. 必须遵守的三条

1. **点按钮中心，不要点边缘**。差 2 px 就会点到旁边的按钮。
2. **每次只做一步，每步都截图复验**。批处理式连点会把状态搞乱且无法定位。
3. **坐标必须按当前截图重新测量**。窗口最大化/移动/换分辨率后，旧坐标全部作废。

## 3. 高 DPI 与坐标换算

- 进程要先 `SetProcessDPIAware()`，否则鼠标坐标与截图坐标差一个缩放系数。
- 我们的工具脚本里约定：截图坐标 = 屏幕物理像素；OCR 输出按截图原尺寸给坐标。
- 若截图被缩放显示（如 2560×1600 显示成 2000×1250），换算系数 = 2560/2000 = 1.28。

## 4. 模态框与提权

- 以管理员权限运行的窗口（如安装目录下的 `DEFORMSetup.exe`）**收不到普通权限进程的合成点击**（UIPI）。
  表现：点 OK 没反应。解决：不要操作提权窗口，或改用其命令行。
- DEFORM 自己的主界面/Pre/Post 是普通权限，可正常点击。

## 5. 菜单与下拉

- 菜单要用**鼠标点击**打开（键盘 Alt 有时不生效）；点开后再点条目。
- Qt 下拉框（如 Post 的 `Object control`）点箭头后，用 `Down/Up + Enter` 选择比点列表更可靠
  （列表的屏幕位置与实际命中区可能差一行）。

## 6. 键盘的边界

- `SendKeys` 发给**前台窗口**；先确认前台标题再发。
- 数值输入框常常只读（如 Post 的 Step 框），以滑块/按钮为准。
- 文件对话框里输入长路径容易被吞反斜杠，逐级双击目录更稳。

## 7. 什么时候不要用这条路

- 需要精确数值输入、批量参数扫描、长时间求解 → 用 KEY + 脚本（L0）。
- 界面版本/语言包不同 → 文字与布局都会变，先截图核对。
- 目标是可复现的交付 → 把关键步骤写成文档 + 截图，而不是留一个点击脚本。

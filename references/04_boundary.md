# 对象、接触、边界与步控

## 1. 对象类型

| 件 | 类型 | 说明 |
|---|---|---|
| 坯料 | **Plastic** | 唯一需要流动应力与细网格 |
| 工作模 / 下模 / 模垫 / 模座 | **Rigid** | 不做模具变形就一律 Rigid |
| 挤压筒 | **Rigid** | |
| 挤压垫 / 挤压杆 | **Rigid** + 运动 | 给速度或载荷，设为 Primary Die |

只算模具强度/磨损时，模具才改 Elastic 或走 Die Stress 流程。

## 2. 接触与摩擦

- `Inter-Object Relations` 先建立全部默认关系，再对特例调整。
- DEFORM 用**剪切摩擦因子 m**（不是库仑摩擦系数）：τ = m·k。
- 热挤铝的经验范围 m ≈ 0.7～1.0（无润滑偏高）；有润滑或氮化工作带低一些。**具体值回到文献/工艺文件取值并写明。**
- 工作带长度直接决定摩擦阻力 → 挤压力，这是把工作带当研究变量的物理依据。

## 3. 传热

- 热挤必须勾 **Heat transfer**，否则温度场不算，热软化、温升全看不到。
- 界面换热系数（IHTC）是热挤里最敏感又最不确定的参数之一；用默认值时 Data Check 会提示警告，可继续，但报告里要做说明或敏感性分析。
- 典型设定：坯料 450～500 °C，模具/挤压筒 400～450 °C（按工艺文件核定）。

## 4. 运动

- 挤压杆给**恒定速度**最简单也最常见（主运动对象设为 Primary Die，方向沿 −Z）。
- 速度过高会让温升与应变速率失真；先按工艺规程给，再做敏感性。
- 也可给载荷，但收敛更差，初学不建议。

## 5. 步控（Simulation Controls）

| 项 | 建议 |
|---|---|
| 步定义 | 按 **Die displacement**（挤压杆位移），最直观 |
| 步长 | 0.1～0.2 mm/步；**必须 ≤ 最小单元边长的 1/3～1/5** |
| 总步数 | 目标行程 / 步长；瞬态动画想看全程就按全程给 |
| 存库间隔 | 每 1 步存一帧（动画要连续）；只要最终结果可放宽到 5～10 步 |
| 停止条件 | 行程 / 最大载荷 / 总步数 |

## 6. 对称性

- 四孔 2×2 布置可用 1/4 模型（两个对称面），单元数直接降 4 倍。
- 用之前确认孔型与流动真的对称；工作带分区不对称时不能用。

## 7. Check Data 的正确读法

- **Error**：必须改，否则 DB 生成失败（如：Workpiece 必须与主模接触、材料缺失）。
- **Warning**：可继续，但要知道含义：
  - "Heat transfer coefficient between objects X and Y" → 用了默认换热系数
  - "Volume compensation has not been activated" → 体积补偿未开（大变形时体积可能漂移）
- 记下所有 Warning，写进报告的方法部分。

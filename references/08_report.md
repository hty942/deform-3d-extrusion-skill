# 报告与归档

## 1. 结构（挤压类）

1. **题目与摘要**：一句话说清做了什么、关键数字。
2. **工艺条件**：坯料/模具温度、杆速、摩擦、换热、材料牌号与来源。
3. **几何与网格**：对象清单、单元数/节点数、最小边长、密度窗口设置。
4. **求解设置**：算法（稳态 ALE / 瞬态 Lagrangian）、步定义、步长、停止条件、求解器位数。
5. **结果**：
   - 载荷-行程曲线（压紧→充填→平台）
   - 应力场、应变场、速度场、温度场（每张图带 Min/Max）
   - 出口速度分布与孔间差
6. **优化**：基线 vs 方案，指标对比表，改了什么、为什么。
7. **讨论与局限**：网格限制、参数假设、未验证项。
8. **结论**：可执行的工艺建议，标明证据等级。
9. **附录**：文件清单、脚本、算例目录。

## 2. 证据等级（必须标）

| 等级 | 含义 | 写法 |
|---|---|---|
| 本机实测 | 自己跑出来、有文件 | "本算例结果，见 dof_c1_out.KEY" |
| 厂商文档 | DEFORM 手册/算例 | "DEFORM v11 挤压算例 3，第 X 节" |
| 文献 | 论文/标准 | 给引用 |
| 推断 | 机理判断 | "推断，未做对比试验" |

## 3. 数值纪律

- 同一物理量只能有一个口径；口径不同必须分开写（例：挤压力 5.176 MN 为截面应力积分，5.754 MN 为 DEFORM 载荷口径）。
- 不要四舍五入到失去区分度：孔间差 10.36% 与 10.4% 在对比表里要保留两位。
- 对比表里标明"差多少"（绝对值和百分比），不要只写"更优"。

## 4. 自动生成报告

```bash
python scripts/make_report.py -i baseline.json opt1.json -o report.html
```

输出自包含 HTML（双击即看），包含：

- 每个算例的指标表
- 基线 vs 方案的差值表
- 可选嵌入图片（把图片放同目录，用 `--images` 指定）

报告是**骨架**：结论段必须人工写，脚本只负责把数字摆对。

## 5. 归档清单

| 文件 | 必须 |
|---|---|
| `<name>.DB` | ✅ |
| `<name>.KEY`（导入/导出） | ✅ |
| `<name>.LOG` / `.MSG` | ✅ |
| 指标 JSON/CSV | ✅ |
| 四场截图 | ✅ |
| 报告 HTML | ✅ |
| 参数变更记录（改了什么） | ✅ |

## 6. 不要做的事

- 不要把瞬态动画库的数值当工艺结论（行程不足，未进稳定段）。
- 不要用截图上的颜色当数值（色标每帧自动定标）。
- 不要省略失败的尝试——优化过程里"哪条路走不通"同样有价值。
